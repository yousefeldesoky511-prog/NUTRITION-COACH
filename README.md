# Nutrition Coach
Open-source Flutter app (Android + iOS, Arabic/English). Meals, macros, weight and profile are stored locally in SQLite.

## Build the APK (no Flutter install needed)
1. Push this folder to a public GitHub repo (branch `main`).
2. Open the **Actions** tab, wait for "Build APK" to finish.
3. Download `app-apk` from the run's Artifacts, unzip, install the APK.

Never commit API keys. AI features (camera + Gemini) are planned for phase 2 and will read the key from in-app settings.
Guidance only, not medical advice.
